# SQLTools para Mac — plan

Base: código fuente oficial de SQLTools 2.5 build 5 (GPLv3) en `fuente_original/`. No se modifica; el trabajo nuevo va en carpetas propias.
Objetivo: versión nativa para macOS con Qt 6 (C++/CMake) + Oracle Instant Client.

## Etapas
1. Núcleo: conectar a Oracle y ejecutar consultas desde la terminal (reutilizando `OCI8`, cambiando `LoadLibrary("oci.dll")` por `dlopen`).
2. Versión mínima: ventana con editor con resaltado, F5 para ejecutar y rejilla de resultados.
3. Uso diario: autocompletado, explorador de objetos, scripts SQL*Plus, exportar a Excel/CSV.
4. Paridad: plegado de código, historial, configuraciones, pulido.

## Pendientes del usuario
- [ ] Instalar Qt 6 (ver abajo)
- [ ] Descargar Oracle Instant Client para macOS (Basic + SDK) de oracle.com
- [ ] Tener una base Oracle de pruebas accesible desde este Mac (alias TNS, usuario de prueba)
