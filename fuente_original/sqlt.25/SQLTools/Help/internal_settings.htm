Internal Settings (Main Window & SQL*Plus)

SQLTools exposes several internal settings that control how the main window behaves. These settings were previously hardcoded, but you can now modify them manually.

Editing Internal Settings

  1. Open the Tools menu and click Open Setting Folder.
  2. Drag and drop sqltools.xml from the Settings Folder into SQLTools.
  3. Locate and edit the following parameters:
    • MainWindowFixedPane
    • MainWindowFixedPaneDefaultHeight

MainWindowFixedPane

Controls which pane remains fixed when the main window is resized. Valid values:

  • 0 – top pane is fixed
  • 1 – bottom pane is fixed (default)

MainWindowFixedPaneDefaultHeight

Specifies the default height (in pixels) of the fixed pane. Default value: 150.

These settings are available starting from version 1.5 build 16.

SQL*Plus Launch Parameters

If you experience issues launching SQL*Plus, you can adjust the following parameters in sqltools.xml:

  • SQLPlusExecutable – path to the SQL*Plus executable
    Example: SQLPlusExecutable="C:\Oracle\bin\sqlplus.exe"
  • SQLPlusCommandLine – command line template used to start SQL*Plus
    Example:
    SQLPlusCommandLine="$(USER)/$(PASSWORD)@$(CONNECT_STRING) $(SYS_PRIVS) @$(FILENAME)"

These parameters are supported starting from version 1.5 build 21.
