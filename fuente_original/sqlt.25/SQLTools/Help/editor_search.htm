Find and Replace in the Editor

The editor's Find (Ctrl+F) and Replace (Ctrl+H) dialog is modeless: it does not block the editor. You can keep it open while you scroll, select and edit text, and it keeps showing live search results as you type. For searching across files on disk see Find in Files.

Working with the dialog

  • Each open document has its own Find/Replace dialog. Invoking Ctrl+F while the dialog is already open brings it to the front and re-targets it at the editor you are working in.
  • Ctrl+F and Ctrl+H switch an open dialog between Find and Replace mode in place — the search text, options and scope are kept.
  • If you select text in the editor before pressing Ctrl+F, the selection is copied into the Find what box and the Selection scope is armed automatically.
  • The dialog remembers its position, the search/replace history (use the drop-down lists or the arrow keys over the field) and all options between sessions.
  • Esc or the caption X closes the dialog and returns the focus to the editor. By default the dialog stays open when it merely loses focus; this can be changed in the settings.

Search as you type (live preview)

  • Shortly after you stop typing (about 300 ms) the dialog searches automatically, jumps to the first match and shows the n of m counter — which match you are on and how many matches there are in total. The counter is also mirrored in the dialog caption.
  • All matches are highlighted in the editor with a translucent overlay; the current match uses a distinct tint. Editing the text refreshes the highlights.
  • Count reports the number of matches without moving the cursor.
  • Prefer classic behaviour? Live preview can be turned off in the settings — searches then run only on Enter, F3, Shift+F3 and the dialog buttons.

Search scope

Scope Description
Selection Search only inside the selected region. Armed automatically when the dialog is opened over a selection; the dialog caption shows the active scope. Searches wrap at the edges of the region.
The current file The whole active document (default).
All Windows All open editor windows. The dialog follows the editor you switch to, so you can keep pressing Find Next across documents.

Search options

  • Match whole word only — skip matches embedded in longer words.
  • Match case — case-sensitive search.
  • Regular expression — pattern search; the button next to the Find what box opens an expression builder with the supported syntax. See Regular Expressions.
  • Backslash escapes — interpret \t, \n and friends in the search/replace text (see Regular Expressions).

Replace

  • Replace replaces the current match (finding one first if needed) and moves to the next.
  • Replace All replaces every match in the active scope. With the All Windows scope you get a single confirmation before the batch runs over all open documents.
  • Replace honours the scope: with Selection only the selected region is modified.

Mark All (bookmarks)

Mark All sets a bookmark on every line containing a match. Combine it with the bookmark commands on the Search menu to walk the hits (Next/Previous Bookmark) or to copy / delete all bookmarked lines at once.

Keyboard

Key Action
Ctrl+F / Ctrl+H Open / re-target the dialog in Find or Replace mode
Enter In the dialog: repeat the search (same as Find Next)
F3 / Shift+F3 Find next / previous — works both in the dialog and in the editor while the dialog is open
Ctrl+F3 / Ctrl+Shift+F3 Find the next / previous occurrence of the currently selected text, without opening the dialog
Esc Close the dialog and return focus to the editor

Settings

Two options in Tools > Settings > Editor > General, group Find/Replace, restore the classic dialog behaviour. Both are off by default and take effect immediately — no restart needed:

Option When checked
Close Find/Replace dialog when it loses focus The dialog closes as soon as the focus moves away from both the dialog and the editor being searched (for example when you click another document or another program) — the classic behaviour. While this is off, the dialog stays open until Esc, the caption X or the Close button dismisses it.
Disable search-as-you-type live preview No automatic searching while you type: searches run only on Enter, F3, Shift+F3 and the dialog buttons. While this is off, typing in the dialog searches after a short pause and shows the match count and the first hit live.
