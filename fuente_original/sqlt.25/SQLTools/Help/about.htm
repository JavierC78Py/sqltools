SQLTools 2.5

Aleksey Kochetov Copyright © 1997-2026

SQLTools is a light weight and robust frontend for ORACLE database. It offers a powerful text editor, a sql console, object browser and a few useful tools. It has small footprint and it is fast as Oracle SQL*Plus. SQLTools does not need an installation so you can copy it on usb stick.

SQLTools is not comprehensive as TOAD or PLSQL Developer and never will provide so much functionality but some people like its clean and fast UI.

System requirements

The program is developed and tested on Windows 11, and should also work on Windows 7 and Windows 10. It is distributed in two versions: a 32-bit build and a 64-bit build.

A properly installed Oracle Client is required. The required client architecture (32-bit or 64-bit) must match the program version being used.

Oracle Client versions from 12c to 21c are tested. The program should also work with a 23c client, although this version is not tested.

Server Requirements

Oracle databases from 12c to 21c are tested. The program should also work with 11g and 23c databases, although these versions are not tested.
