# SQLTools Mac — Manual del usuario

**SQLTools Mac** es la versión nativa para macOS de SQLTools, el cliente Oracle para desarrolladores PL/SQL y APEX. Conserva los menús, atajos, iconos y la velocidad del original de Windows, y añade cosas propias del Mac (Llavero, modo oscuro, Terminal).

> Este manual se genera a partir de archivos de texto y de capturas tomadas por el propio programa, así que las imágenes siempre corresponden a la versión que tiene instalada. Las pantallas usan **datos ficticios**.

## Convenciones
- Los atajos usan los símbolos del Mac: **⌘** Comando · **⌥** Opción · **⇧** Mayúsculas · **⌃** Control.
- **⌘K, T** significa: pulse ⌘K, suéltelas y luego pulse **T**.
- Las teclas **F1…F12** pueden requerir **Fn** (o active «Usar teclas F1, F2… como teclas estándar» en Ajustes del Sistema → Teclado).
- Las rutas de menú se escriben así: **Session > Connect…**.
